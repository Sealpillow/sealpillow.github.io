Personal project

A QA runner that walks the whole storefront

Checking every storefront by hand before a release was slow and easy to get wrong. So, as a personal project, I built a test runner that walks the shopper's path on each market and writes up what it found. It's now also used for regression testing at work.

  • 38 tests and a 51-step shopper journey on desktop and phone
  • 25 markets, with browsers running in parallel
  • A sign-off report and a staging vs live comparison from any run
